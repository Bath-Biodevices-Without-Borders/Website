Accessibility statement

Last updated 28 October 2026

This website is run by Bath Biodevices. We want as many people as possible to be able to use it. We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

What we've done

  • You can use the whole site with a keyboard alone, with a visible focus outline, and there's a link to skip straight to the main content.
  • Text and controls meet WCAG contrast requirements.
  • You can zoom in to at least 200% without losing content or needing to scroll sideways.
  • Pages use proper headings, landmarks and labels so they work with screen readers.
  • Images have text alternatives, and the diagram of our rig is described in words.
  • Animations turn off if your device is set to reduce motion, and nothing flashes.
  • Numbers that count up on screen are given to screen readers in full straight away.

Known limitations

  • Some of the sources we link to are on other websites that we don't control, and they may not be fully accessible.
  • The team section needs JavaScript to display. If JavaScript is turned off, you'll see a message explaining this.

Feedback

If you find a problem, or need any information from this site in a different format, email Sascha at shl200@bath.ac.uk or Sofiia at sb3889@bath.ac.uk. We aim to reply within 10 working days.

How we tested this site

This statement was prepared on 28 October 2026. We tested the site with automated accessibility checks (axe), keyboard-only navigation, reduced-motion settings, and a range of screen sizes from mobile to large desktop.
